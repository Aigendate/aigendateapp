## Commands

```bash
npm run dev          # Dev server with HMR on port 3456
npm test             # Run all 33 tests (vitest)
npm run test:watch   # Tests in watch mode
npx vitest run tests/server/db.test.ts  # Single test file

```

## Architecture

Single Express server (`server.ts`) serves both a React Router 7 SSR app and an MCP HTTP endpoint:

- **`/mcp`** is handled by `StreamableHTTPServerTransport` before any other middleware
- **`/*`** falls through to React Router's `createRequestHandler`
- In dev, Vite runs in middleware mode between these two

### Shared database layer

`server/db.ts` is imported by both RR7 route loaders and MCP tools. Key patterns:

- **`getDb(dbPath?)`** returns a singleton stored on `globalThis.__turnos_db` (survives Vite HMR)
- Accepts `:memory:` for tests, defaults to `process.cwd()/turnos.db`
- `server/db.server.ts` re-exports everything — route loaders import from here so RR7's `.server.ts` convention prevents client bundle leakage of `better-sqlite3`

### MCP

`server/mcp.ts` exports `createMcpServer(dbPath?)` which registers 7 tools. Two entry points:
- `mcp-stdio.ts` — standalone stdio transport (what `.mcp.json` points to)
- `server.ts` — HTTP transport mounted at `/mcp` with CORS and session management

### Route conventions

Routes use RR7's typed loader pattern:
```typescript
import type { Route } from "./+types/hospitales";
export function loader({ request }: Route.LoaderArgs) { ... }
export default function Component({ loaderData }: Route.ComponentProps) { ... }
```

The `+types` modules are auto-generated by `react-router typegen` (runs as part of `npm run typecheck`). They live in `.react-router/types/` and are gitignored.

Loaders call `getDb()` and use query functions from `server/db.server`. URL search params drive filtering (e.g., `?q=`, `?date=`, `?status=`).

## Testing

Vitest with node environment. Tests use in-memory SQLite — no DB file needed.

```typescript
let db: Database.Database;
beforeEach(() => { db = initDb(":memory:"); });
afterEach(() => { db.close(); (globalThis as any).__turnos_db = undefined; });
```

Always reset `globalThis.__turnos_db` in `afterEach` to avoid singleton leakage between tests.

Test files: `tests/server/db.test.ts` (DB queries), `tests/server/mcp.test.ts` (MCP server), `tests/routes/loaders.test.ts` (route loaders), `tests/integration/server.test.ts` (Express + MCP HTTP).

## Vite/SSR gotchas

- `better-sqlite3` must stay in `ssr.external` in `vite.config.ts` — it's a native C++ addon
- DB paths use `process.cwd()`, not `import.meta.url` — the latter breaks after Vite bundles SSR code
- The `~` alias resolves to `./app` in both vite.config.ts and tsconfig.json

## Data

`data/` contains Paraguay health facility CSVs from OpenStreetMap. `scraper/paraguay_hospitals.py` re-fetches them (requires `pip install requests`). After scraping, re-run `npm run seed`.
